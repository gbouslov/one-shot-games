# Where to go when you need more

Stars and licences as read from GitHub on 10 Nov 2026.

## Larger systems

| Repo | Use it for | Licence |
|---|---|---|
| [Donchitos/Claude-Code-Game-Studios](https://github.com/Donchitos/Claude-Code-Game-Studios) | A full game studio in Claude Code: 49 agents, 72 skills, design documents, engine routes, a guided path from idea to release. The right choice for a game you intend to keep working on. | MIT, about 37,600 stars |
| [gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills) | 77 engine skills and a router: Godot, Unity, Unreal, Phaser, PixiJS, three.js, Bevy and more, written from primary docs. The right choice for a game outside the browser. Five are copied into `third_party/skills/`. | Apache-2.0 |
| GameGen-Verifier (an anonymised research release) | State-grounded verification of generated browser games: distils what a game claims to do into checkable points and verifies each with Playwright. Read its `skills/` for deeper playtest design. | MIT |
