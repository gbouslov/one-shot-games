## The prompt, exactly as posted

```text
Step 1 -> A canvas, a starfield, a ship that moves on arrows and touch. No enemies yet.

Step 2 -> Auto fire and one enemy type that dives. Play it until the dodge feels right.

Step 3 -> Waves. Each one tighter, with a "WAVE 2" banner so you know the game noticed.

Step 4 -> Power-ups: spread shot, shield, score bonus, each dropped from a kill.

Step 5 -> Score, best score, lives, a pause key, a game over screen that restarts on space.

Step 6 -> Each model reviews its own build and fixes what it finds before I touch anything.
```

## How to use it

Each step is checkable before the next one starts.

Add the standard ending from [`prompts/DELIVERY.md`](../DELIVERY.md) before you send it.
