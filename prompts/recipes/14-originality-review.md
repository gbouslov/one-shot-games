## The prompt, exactly as posted

```text
1. list every mechanic, name, asset and level that matches a specific existing game. don't write any code yet.
2. for each match, propose an original replacement that keeps the genre feel.
3. rewrite the spec with only my own designs and assets, and mark anything i'd need rights for.
4. stop there and wait for my yes before you build anything.
```
